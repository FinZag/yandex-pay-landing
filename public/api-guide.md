# FinGame — оплата в приложении

Все ответы в формате JSON, кодировка UTF-8, валюта — рубли.

## 1. Проверка связи

```
GET https://fingame-coder.ru/ping.txt
```

Ответ — текст `OK`. Если пришёл `OK`, интернет есть и сервер отвечает.

Расширенная проверка, показывает ещё и готовность платёжного шлюза:

```
GET https://functions.poehali.dev/f089d5db-508b-44ef-bc3b-bfa5e422629b?format=json
```

```json
{ "status": "ok", "payments": true, "time": 1788335601 }
```

`payments: false` — магазин временно недоступен, кнопку покупки лучше скрыть.

## 3. Список товаров игры

```
GET <адрес магазина>?gameId=bytetrace
```

```json
{
  "gameId": "bytetrace",
  "game": "ByteTrace",
  "products": [
    { "productId": "no-ads", "title": "Отключение рекламы", "amount": 199 }
  ]
}
```

Цены задаются на сервере. Не зашивайте их в приложение — берите из этого ответа.

## 4. Покупка товара

```
POST <адрес магазина>
Content-Type: application/json

{
  "gameId": "bytetrace",
  "productId": "no-ads",
  "playerId": "player-42",
  "email": "player@example.com"
}
```

`playerId` — ваш идентификатор игрока: латиница, цифры, дефис, подчёркивание, до 64 знаков.
`email` — обязателен, на него ЮKassa отправляет чек.

Ответ:

```json
{
  "paymentUrl": "https://yoomoney.ru/checkout/...",
  "orderId": "game-3ec70f89c51f45b889cde9817e5a6d05",
  "gameId": "bytetrace",
  "productId": "no-ads",
  "amount": 199,
  "title": "Отключение рекламы"
}
```

Откройте `paymentUrl` во встроенном браузере, `orderId` сохраните.

## 5. Подтверждение покупки

```
POST <адрес магазина>
Content-Type: application/json

{ "orderId": "game-3ec70f89c51f45b889cde9817e5a6d05" }
```

Оплата ещё не прошла:

```json
{ "status": "pending", "orderId": "...", "gameId": "bytetrace", "productId": "no-ads", "playerId": "player-42" }
```

Оплата прошла — выдавайте товар:

```json
{
  "status": "paid",
  "orderId": "...",
  "gameId": "bytetrace",
  "productId": "no-ads",
  "playerId": "player-42",
  "amount": 199,
  "alreadyDelivered": false
}
```

`alreadyDelivered: true` — товар по этому заказу уже выдавался ранее.

Как опрашивать: после возврата из браузера — раз в 2 секунды, до 10 попыток. Если статус
остался `pending`, повторите проверку при следующем запуске игры. Незавершённые заказы
храните локально и проверяйте при старте — так покупка не потеряется, если игрок закрыл
приложение во время оплаты.

## 6. Ошибки

| Код | Значение |
|-----|----------|
| 400 | Неверные данные запроса — товар, игрок или почта |
| 404 | Игра или заказ не найдены |
| 502 | Платёжный сервис недоступен, повторите позже |
| 503 | Приём платежей временно выключен |

Тело ошибки: `{ "error": "текст для показа игроку" }`

## 7. Важное

- Решение о выдаче товара принимает только сервер, по ответу `status: paid`.
- Секретные ключи в приложении не нужны — их хранит сервер.
- Пока магазин в тестовом режиме, деньги не списываются.
- Страница возврата после оплаты — `https://fingame-coder.ru/pay/done`.
